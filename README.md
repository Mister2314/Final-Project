# GameStorm — Gaming Studio Landing Page

A long-form landing page for a fictional game studio: hero slider, feature blocks, gallery, team, testimonials and store CTAs.

## What it does

A full marketing-page structure built by hand across ten sections — about, features, office gallery, team, social proof, testimonials and App Store / Google Play buttons — all laid out with CSS grid and flexbox. The JavaScript stays small on purpose: a custom cursor that follows the mouse and a typewriter effect for the headline are the only behaviours; everything else is markup and CSS.

## Tech stack

React 19 · TypeScript · Vite

## Features

- Ten-section marketing layout in one page, CSS grid and flexbox throughout
- Hero banner slider section
- Typewriter headline effect with randomized typing speed
- Custom cursor that tracks the mouse with a trailing second element
- Testimonial cards and social-proof grid
- App Store / Google Play download CTAs
